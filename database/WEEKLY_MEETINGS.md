# 주간 회의록 운영 및 기존 DB 이관

주간 회의는 매주 첫 번째 근무일에 진행하고, 지난주에 수행한 일을 보고한다. 회의일과 보고 기간을 구분한다. 회의일이 포함된 주의 월요일~일요일을 이번 주로 보고, 직전 주 월요일~일요일을 지난주 보고 기간으로 표시한다. 예: 2026-10-06(화) 회의의 보고 기간은 2026-09-28~2026-10-04다.

휴무일 때문에 회의가 화요일 등으로 바뀌면 실제 회의 일시를 선택한다. 공휴일/회사 휴무 캘린더를 자동 조회하거나 회의를 자동 예약하지는 않는다. 이번 주 회의록이 이미 있으면 새 작성 화면의 날짜 제안에도 실제 회의일을 사용한다. 없으면 월요일 10시를 제안하며 사용자가 첫 근무일과 시간을 수정한다.

작성 화면은 다음 세 항목으로 구성한다.

1. 지난주 진행 내용: 방문·PM·수리·테스트와 실제 결과.
2. 진행 중인 일·이슈: 계속 진행하는 작업, 실패 원인, 재수리 필요, 병원별 문제.
3. 이번 주·예정 작업: 이번 주 계획, 향후 정전·업그레이드 등의 예정 작업.

제목은 비우면 실제 회의 날짜로 생성한다. 참석자는 확인된 사람만 선택하며 자동으로 전체 사용자를 참석자로 넣지 않는다.

DB는 기존 meetings/meeting_participants/file_links를 그대로 사용한다. 본문 content_markdown에는 위 항목을 h2로 구분한 HTML을 저장한다. 기존에 한 본문으로 작성한 HTML/Markdown 회의록은 수정 화면의 ‘지난주 진행 내용’에 원문을 넣고 유지한다. 새 항목을 작성해도 기존 본문을 삭제하지 않는다. 데이터 이관 시 본문, 회의 일시, 작성자, 마지막 수정자, 참석자, 첨부를 모두 보존한다.

2026-10-07 운영 DB를 확인했을 때 10월 6일 회의록은 없었다. 사용자 요청으로 ‘10월 6일 주간 회의록’을 새로 작성했다(운영 ID 2). 회의 시간은 기존 작성 화면의 기본값인 10:00으로 입력했다. 실제 참석자는 전달받지 않아 비워두었다. 기존 9월 14일 회의록은 변경하지 않았다.

추가 내용: VRE Power Supply 2EA 수리 완료, 구형 Gradient Power Supply 2EA 테스트 후 수리 실패·재수리 필요, 드라이버 모듈 2EA 중 좌측 PCB 교체(순천향병원 ↔ 일등병원), RF AMP 수리 세팅, 정병원 멀티모듈 Spine Y/6채널 코일 문제, 평택 PM(10월 7일 수요일), 강북우리 정전(11월 3일), 바르다임 방문, 일등병원 100A → 120A 업그레이드 예정이다.
